# START HERE (Claude Code on the web)

1. Create an empty private repo on GitHub: github.com/new → name `thinking-budgets-forecasting`, Private,
   leave "Add a README" unchecked → Create repository.
2. On the new repo page click "uploading an existing file", drag in ALL the files and folders from inside this
   unzipped folder (configs, data, docs, scripts, src, tests, paper and the top-level .md/.txt/Makefile files),
   then "Commit changes".
3. Go to claude.ai/code → New session → choose the repo → paste the prompt from the chat.

`gitignore.txt` is a visible copy of `.gitignore` (dot-files don't upload from the browser); Claude Code renames it.
