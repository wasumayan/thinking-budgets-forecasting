# paper/

Download the NeurIPS 2026 style files (neurips_2026.sty) from the FMTS CFP / neurips.cc and place them here.
`main.tex` is written in Stage 6 of the playbook from results/summary.csv, results/paired.csv, figures/ and
paper/tables/. Use `\usepackage[final]{neurips_2026}` when checking the 4-page limit. Anonymized submission:
no author block, no acknowledgements, no identifying repo link.
